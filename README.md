# orange3-smiles-plugin
这是一个基于Orange3的插件，用于处理SMILES数据。该插件提供了多种功能，包括SMILES数据的导入、处理和可视化，帮助用户更方便地分析和理解化学结构数据。
## 功能特点
- **SMILES数据导入**：支持从多种格式（如CSV、TXT等）导入SMILES数据，方便用户快速加载化学结构信息。
- **数据处理**：提供多种工具用于处理SMILES数据，包括去重、过滤、转换等
## 如何使用
请先确保你已经安装orange3，然后在Orange3中安装本插件。安装完成后，你可以在Orange3的工具栏中找到相关功能，按照提示操作即可。
