# Orange3 SMILES Plugin

这是一个基于 [Orange3](https://orangedatamining.com/) 数据挖掘平台的开源插件。该插件专为化学信息学（Cheminformatics）领域设计，旨在将强大的 RDKit 分子处理引擎无缝接入 Orange3 的可视化数据流管线中。

通过本插件，用户无需编写任何代码，即可通过拖拽组件的方式，实现从 SMILES 字符串到高维分子物理化学特征的自动提取，并提供独立的二维拓扑结构渲染能力，极大地方便了将化学结构数据直接应用于机器学习与数据挖掘任务。

---

## 核心组件与功能

本插件向 Orange3 系统注册了三个核心的图形化组件，分别位于底层的 `Data` 和 `Visualize` 分类中：

### 1.  SMILES Features Transformer (SMILES 特征转换器)
*   **所属分类**：`Data`
*   **核心功能**：自动接收上游数据表，允许用户手动勾选包含 SMILES 序列的文本列。组件调用底层的 RDKit 引擎，将选定的 SMILES 批量转换为对应的分子对象，并计算出 **25 种核心的分子物理化学与拓扑特征符**（如分子量、LogP、TPSA、氢键供体/受体数量等）。
*   **输出格式**：将计算生成的高维特征矩阵作为连续型变量（Continuous Variables），横向拼接到原始实验数据表后，输出标准且完整的 `Orange.data.Table`，可直接接入任何机器学习模型节点。

### 2.  SMILES Viewer (表格分子查看器)
*   **所属分类**：`Visualize`
*   **核心功能**：与数据流管线深度绑定。接收包含 SMILES 列的数据集后，允许用户通过下拉菜单与列表框交互，快速选择并定位特定的分子样本。系统会在右侧的主视图区实时渲染生成该目标分子的二维高分辨率拓扑结构图。

### 3.  Single SMILES Drawer (独立分子绘制器)
*   **所属分类**：`Visualize`
*   **核心功能**：完全独立于数据流管线。提供一个极简的交互面板，用户可直接键入任意合法的 SMILES 字符串，系统将即时生成并渲染其二维分子图像。适用于快速的结构验证与教学演示。

## 依赖环境

在安装本插件之前，请确保您的 Python 环境中已正确部署以下依赖：

*   **Orange3** (核心宿主框架)
*   **RDKit** (底层化学信息学与图像渲染引擎)
*   **NumPy** (高维特征矩阵运算)
*   **AnyQt** (图形界面底层桥接库)

---

## 安装与配置指南

### 本地开发者模式安装 (Recommended)

1.  请确保您已进入 Orange3 所在的 Python 虚拟环境。
2.  将系统终端的路径切换至本插件工程的根目录（即包含 `setup.py` 文件的目录）。
3.  执行以下命令以可编辑模式（Editable Mode）注册并安装插件：
    ```bash
    pip install -e .
    ```

5.  重新启动 Orange 主程序。在左侧的组件工具栏中，即可在 `Data` 和 `Visualize` 分类下找到新增的三个组件。

---

## 工作流演示示例

1.  **导入数据**：使用内置的 `File` 组件加载包含反应物 SMILES 和实验目标值（如产率 `Yield`）的 CSV 表格。确保系统将 SMILES 列识别为 `Text/Meta`。
2.  **特征扩增**：将 `File` 节点的输出端连接至 `SMILES Features Transformer` 节点。双击打开面板，勾选所有的反应物 SMILES 列并执行运算。
3.  **结果导出/建模**：将转换后的输出端接入 `Data Table` 验证生成的 25 维扩展特征列，或直接接入 `Random Forest` 等机器学习模型组件开展数据挖掘任务。
4.  **结构核验**：将 `File` 或转换后的数据分支接入 `SMILES Viewer` 节点，点选任意行记录，直观检视其分子拓扑结构。
